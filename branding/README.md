# Logo de Meridian 26H2

**Idea:** un globo partido por el meridiano; la mitad derecha va adelantada. Corte (quitar lo que sobra) y velocidad.

## Archivos (`final/`)
| Archivo | Uso |
|---|---|
| `meridian-symbol.svg` | Símbolo a color, sobre fondo oscuro |
| `meridian-symbol-black.svg` / `-white.svg` | Una sola tinta, sobre claro / oscuro |
| `meridian-symbol-small.svg` | Corte para tamaños pequeños (16-32 px): hueco y desplazamiento más grandes |
| `meridian-app-icon.svg` | Icono de app y favicon (fondo `#0f0f0f`) |
| `meridian-lockup-horizontal*.svg` | Símbolo + MERIDIAN 26H2 en línea |
| `meridian-lockup-stacked.svg` | Símbolo arriba, nombre debajo |

Iconos web en `web-icons/`, ya copiados a `docs/` (favicon.ico, favicon.svg, apple-touch-icon, icon-192/512, maskable, site.webmanifest).

## Colores
| Nombre | HEX | RGB |
|---|---|---|
| Lima (acento) | `#dafa9c` | 218 250 156 |
| Hollín (fondo) | `#0f0f0f` | 15 15 15 |
| Blanco | `#ffffff` | 255 255 255 |

El lima no tiene contraste sobre blanco: sobre fondos claros usa siempre la versión negra de una sola tinta.

## Reglas
- **Espacio libre:** alrededor del logo, como mínimo el ancho del hueco central multiplicado por 2.
- **Tamaño mínimo:** símbolo de 16 px (con `meridian-symbol-small.svg`); logo horizontal de 120 px de ancho.
- **No hacer:** girar el símbolo, invertir qué mitad va adelantada, cerrar el hueco, añadir sombras o degradados, ni cambiar la tipografía del nombre.

## Tipografía
El nombre está dibujado como trazos a partir de **Archivo** (anchura 62, peso 800), con licencia SIL Open Font License (`final/Archivo-OFL.txt`), que permite usarla en logos. La web usa la misma familia.
