# Código fuente de Meridian 26H2

Todo lo que hace Meridian 26H2 está aquí en texto plano:

- `playbook/playbook.conf`: identidad del playbook, requisitos y páginas del asistente de AME Wizard.
- `playbook/Configuration/`: las acciones (YAML) que ejecuta AME Wizard.
- `playbook/Executables/`: scripts y la carpeta «Atlas» que se copia al escritorio.
- `dependencies/local-build.ps1`: compila el `.apbx`.

Para compilar, lee la sección «Compilar desde el código» del [README principal](../README.md).
La documentación de desarrollo de AtlasOS explica la estructura del playbook: <https://docs.atlasos.net/contributing/playbook/>.
