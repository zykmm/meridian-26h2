How to install AtlasOS on Windows 11 26H2

AtlasOS 0.5.0 does not support build 26300. This guide explains why and how to apply Meridian 26H2, its unofficial fork for 26H2, step by step.

Updated 1 November 2026 · by zykmm

First: Meridian 26H2 is an unofficial AtlasOS fork, not affiliated with the Atlas team. On 24H2 or 25H2, install the official AtlasOS; this guide is for 26H2 only.

Why AtlasOS will not install on 26H2

AtlasOS 0.5.0 lists its supported builds in playbook.conf: 26100 (24H2) and 26200 (25H2). Windows 11 26H2 is build 26300, so AME Wizard rejects the official playbook. The Atlas documentation does not list 26H2 either.

Removing that check is not enough: 26H2 changes things the playbook touches. UCPD blocks Widgets and the default browser during install, new apps such as Quick Assist and CrossDevice arrive, and the Copilot app leaves 1.1 GB behind. Meridian fixes these, among the 79 changes logged in CAMBIOS-26H2.md (Spanish).

Requirements

  • Windows 11 26H2, build 26300, fully updated. Check with Win + R → winver.
  • A backup. There is no uninstaller: going back to stock Windows means reinstalling it.
  • The latest AME Wizard.
  • Internet on, PC plugged in, no third-party antivirus.

Step-by-step install

  1. Download Meridian-26H2-v1.0.0.apbx and its .sha256 from the latest release.
  2. Check the download in PowerShell and compare it with the .sha256 file: 
    (Get-FileHash .\Meridian-26H2-v1.0.0.apbx -Algorithm SHA256).Hash
    The v1.0.0 scan on VirusTotal shows 0 of 62 (it is a password-protected ZIP, so some engines cannot look inside).
  3. Open AME Wizard and drop the .apbx onto the window.
  4. AME checks the requirements and walks you through turning off Defender and UCPD for the install.
  5. Pick your options: Defender, CPU mitigations, automatic updates, browser and whether to remove Edge. If unsure, keep the recommended ones.
  6. Wait about 15 minutes without turning the PC off. AME reboots when done.
  7. Sign in: postReboot.ps1 applies Widgets and the default browser on first sign-in.
  8. If you kept Defender on, turn Tamper Protection back on. Meridian reminds you with a prompt.

Check the result

Download verificar-26h2.ps1 and run it as administrator. It only reads the system and writes a report without your PC or user name (the report is in Spanish):

powershell -NoProfile -ExecutionPolicy Bypass -File .\verificar-26h2.ps1 -Nombre mypc

On the test virtual machine the result was 66 OK, 0 FAIL.

Common problems

What you seeWhat to do
AME says the Windows version is not supportedCheck winver: it must say 26300. On 26100 or 26200 use the official AtlasOS.
AME asks to install pending updatesInstall them all in Windows Update, reboot and open AME again.
Defender flags Remove-Edge.exeA reputation-based detection common with PyInstaller executables. It does not affect the install. Meridian downloads version 2.3 and checks its SHA256.
Atlas Toolbox shows a state that looks wrongThose are Toolbox 0.1.13's own bugs. What the playbook applies is correct.

Something else? Open an issue with your build, your options and the logs in C:\ProgramData\AME\Logs.
