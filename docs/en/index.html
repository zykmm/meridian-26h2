Meridian: AtlasOS on Windows 26H2.

Meridian 26H2 is an unofficial fork of AtlasOS 0.5.0, adapted and audited for Windows 11 26H2 (build 26300). Apply it with AME Wizard in about 15 minutes.

Screenshots from the test virtual machine, Windows 11 Pro 26300 with Meridian applied.

Download the .apbx

A fork, plainly

AtlasOS 0.5.0 shipped for 24H2 and 25H2. Meridian takes that playbook to Windows 11 26H2, build 26300.

It is not made or endorsed by the Atlas team. Report Meridian bugs here, never to Atlas.

Every change from 0.5.0 is logged with its reason: 190 YAML files reviewed, 79 documented changes, same GPLv3 licence. Read the full change log (Spanish)

What changes on 26H2

  • Widgets, after rebootF3-1 On 26H2, UCPD blocks the Widgets policies and the default browser during install. Meridian applies them after the first reboot with postReboot.ps1, checks the result and retries up to five times.
  • A version lock that worksB2-3 The target version goes into TargetReleaseVersionInfo. Atlas 0.5.0 wrote it over TargetReleaseVersion as text, and Windows Update ignored the lock.
  • Edge out, SHA256 checkedB1-1 Remove-Edge.exe is pinned to version 2.3 and checked against its published hash. If it does not match, it does not run. No more prompts halfway through the install.
  • Copilot, no leftoversF5-5 Removing the Copilot AppX left 1.1 GB behind: its Chromium app in Program Files (x86), a service, registry keys and a shortcut. Meridian runs its official uninstaller and deletes the rest.
  • Firewall in any languageF3-4 The 15 Remote Assistance firewall rules are disabled by their internal group, which is the same in every language. Before, they were matched by English name, and on non-English Windows none were found.
  • New 26H2 apps removedD4 Quick Assist and CrossDevice go. Frameworks such as WindowsAppRuntime are no longer deprovisioned by mistake, so apps that rely on them keep working.
  • Your choices, keptD1 DEFAULT.ps1 also runs on a clean install and keeps what you pick in the wizard: automatic updates, hibernation and Defender.
  • Atlas folder, consistentF3-13 Every Atlas folder script saves its state with the real Atlas Toolbox 0.1.13 numbering, so Toolbox shows what is actually applied.

Nothing by that name. Check the full change log.

Before you install

Is this official AtlasOS?

No. It is an unofficial fork of the AtlasOS 0.5.0 playbook (commit 6c26aab), not affiliated with the Atlas team. It uses their code under the GPLv3 licence, with thanks; internal names such as the "Atlas" folder or Atlas Toolbox stay because the scripts depend on them.

Does it contain malware?

The whole playbook is plain text in the repository, and GitHub Actions builds every release from it. Each release publishes its SHA256. The v1.0.0 file scores 0 of 62 on VirusTotal.

An honest note: Defender may flag Remove-Edge.exe as Trojan:Win32/Yomal!rfn, a reputation-based detection common with PyInstaller executables. Meridian downloads a pinned version and checks its hash before running it.

Can I undo it?

There is no uninstaller, just like AtlasOS. Many options can be changed later from the Atlas folder or Atlas Toolbox, but going back to stock Windows means reinstalling it. Back up first.

Does it work on 24H2 or 25H2?

No: the wizard only accepts build 26300. For 24H2 and 25H2 there is the official AtlasOS, at atlasos.net.

What is the file password?

An .apbx is a renamed ZIP with the password malte, shared by every AME playbook. Use it to open the file with 7-Zip and review what is inside.

Any known issues?

One, and it is not Meridian's: Atlas Toolbox 0.1.13 has its own bugs showing some states (Terminals, Mitigations, indexing). What the playbook applies is correct.

The other note is Defender and Remove-Edge.exe, explained under "Does it contain malware?".

Where do I report a bug?

In the repository issues (English or Spanish), with your build, the options you chose and, if you can, the logs in C:\ProgramData\AME\Logs. Never to the Atlas team.
